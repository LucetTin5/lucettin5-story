# lucettin5-story

마크다운 기반 블로그 프로젝트

## 기술 스택

- **프레임워크**: Tanstack Start (React 19)
- **런타임**: Bun
- **스타일링**: Tailwind CSS v4
- **UI 컴포넌트**: Shadcn UI
- **콘텐츠**: Markdown
- **폰트**: Pretendard
- **테마**: 다크모드 전용, 녹색 계열

## 주요 기능

- 📝 **Posts**: 마크다운 파일 기반 블로그 포스팅
- 🔍 **Search**: 포스트 검색 기능
- 📧 **Contact**: 연락처 페이지
- 🌐 **다국어**: 한국어(메인), 영어
